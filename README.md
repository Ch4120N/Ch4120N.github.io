## 📖 About
Welcome to the source code of my personal cybersecurity portfolio. This repository hosts a fully responsive, single-page application designed to showcase my skills, projects, and professional journey in an engaging, hacker-centric way. 

Instead of a traditional static resume, this webpage features an **interactive web terminal** where visitors can execute commands to explore my background, fetch my latest GitHub repositories dynamically, and navigate through my expertise.

## ✨ Features

### 🖥️ Interactive Web Terminal
- **Kali Linux-Style Prompt**: Authentic multi-line prompt with colored user, host, and path.
- **Command Execution**: Over 20 commands to explore the resume (`help`, `skills`, `repos`, `contact`, etc.).
- **Auto-Completion**: Press `TAB` to auto-complete commands.
- **Command History**: Use `↑` and `↓` arrow keys to navigate previous commands.
- **Beautiful Outputs**: Card-based UI, progress bars, and tables for terminal outputs.

### 🎨 UI/UX & Animations
- **Global Particle Network**: A dynamic, interactive canvas background that connects nodes across the entire viewport.
- **Custom Cursor**: A sleek, bordered dot-and-outline cursor that adapts to interactive elements.
- **Dark/Light Mode**: Seamless theme toggling with persistent local storage.
- **Smooth Scroll & Animations**: Staggered fade-ins, animated progress bars, and hover effects.

### 🚀 Dynamic Content
- **GitHub API Integration**: Automatically fetches and paginates all public repositories, complete with language colors, stars, and forks.
- **Live Stats**: Integration with GitHub Readme Stats and Streaks.
- **Random Quotes**: Rotating cybersecurity and programming quotes.

### 🛡️ Professional Sections
- **Skills & Mastery**: Animated progress bars and Devicon tech stack grid.
- **Professional Journey**: Interactive timeline of experience.
- **Certifications & Goals**: Visual roadmaps and achievement badges.
- **Crypto Donations**: Secure copy-to-clipboard functionality for BTC, ETH, and USDT addresses.

## 🚀 Local Development
Since this is a static website, running it locally is extremely simple.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ch4120N/Ch4120N.github.io.git
   cd Ch4120N.github.io
   ```

2. **Run with a local server:**
   You can use any static server. For example, using Python:
   ```bash
   python -m http.server 8000
   ```
   Or use the **Live Server** extension in VS Code.

3. **Open your browser:**
   Navigate to `http://localhost:8000`.
